# 游戏本地化专家（localization-expert）

面向 Cindy 的标准 Skill，主要用于中文游戏文本译成外语，也支持指定的其他语言方向及译文校对。

重点处理逐字翻译、中文句式残留、角色语气不一致等问题，同时保护游戏机制、剧情事实、术语、变量和资源格式。覆盖对白、剧情、任务、技能、道具、界面及活动文案；不预设目标语言，不将英语规则套用到所有语种。

## 安装到 Cindy

将本仓库作为 `localization-expert` 文件夹放入 `~/.agents/skills/`，确保路径为 `~/.agents/skills/localization-expert/SKILL.md`，然后新建或重启 Agent 会话。仅供某个项目使用时，可放在该项目的 `.agents/skills/` 中。

本仓库已从旧版插件改为标准 Skill：`SKILL.md` 是入口，`references/` 提供示例，`agents/openai.yaml` 提供界面元数据。旧版 `.cindy` 插件包和内置 Excel 工具已移除；更新仓库不会自动更新已安装的旧插件，如仍启用旧插件，应在 Cindy 中停用它，避免旧指令同时生效。

## 使用示例

```text
/localization-expert
目标语言：英语（en-US）
游戏类型：奇幻角色扮演游戏
文本用途：探索对白
角色：寡言的老练佣兵，语气冷淡，不使用现代网络梗
术语：生命值统一为 HP；背包界面统一为 Inventory
格式：保留字符串 ID 和 {name} 等变量，每条对应原条目

待翻译文本：
dialogue_001：来都来了，进去看看吧。
```

可以提供其他目标语种、地区、术语表、角色样例及长度约束。默认输出一版最终译文；需要备选、校对说明、Excel 或其他文件时，在任务中明确要求，文件生成依赖当前 Agent 可用工具。

## 质量范围

Skill 要求先独立通读目标语言，再对照原文复核含义与格式。示例用于说明判断方法，不代表固定答案或官方译法。规则和结构检查不能替代真实项目的母语审校、机制核对与游戏内显示测试。
