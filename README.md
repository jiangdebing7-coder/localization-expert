# 本地化专家（localization-expert）

一个 Cindy 插件：按文本用途翻译或对照原文校对，并把结果直接交付为真实 Excel（.xlsx）文件。

- 广告词、营销文案：允许创意改写，不拘泥原句，但不改变产品事实与承诺
- 规则介绍、说明、技术文档：严格忠实原意，保留条件、否定、数量等关键信息
- 格式适配：按目标语言与媒介处理标点、段首缩进、数字日期等，不机械照搬中文习惯
- 占位符保护：变量、标签、URL、代码等固定片段逐字保留，内置检查工具辅助核对

## Excel 交付

| 任务 | 列结构 |
| --- | --- |
| 翻译 | 原文、译文 |
| 校对 | 原文、修改前译文、修改后译文、修改原因 |

- 单条文本（哪怕一句话）也会生成可下载的 Excel 文件
- 校对包含无需修改的条目，原因列写“无需修改”，方便整列使用
- 单元格均为文本，保留前导零、换行、标签与占位符；首行冻结、自动换行、带筛选

## 安装

方式一（最简单）：下载 `dist/localization-expert-1.1.0.cindy`，在 Cindy 中导入安装。

方式二（从源码打包）：在 Cindy 对话中使用 Forge 打包流程，指向本仓库目录即可。

## 使用

在 Cindy 对话中输入：

```text
$本地化 把这段规则说明翻译成英文：……
$本地化 校对这些译文：……
```

也可以直接说“翻译/校对这段文本”，Cindy 会自动调用本插件。
